# Generated code — do not hand-edit

This directory is the output of `contracts/codegen/generate.sh`, run against
`contracts/schemas/*.json`. Import from here (`contracts_generated.<entity>`)
in every service — never redefine a schema locally.

Run `../codegen/generate.sh` after any change to `contracts/schemas/` and
commit the regenerated output in the same PR as the schema change (see the
CODEOWNERS entries for who must sign off).
